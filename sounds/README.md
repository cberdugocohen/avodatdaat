# Sound Files for Merhav Hadaat

This directory contains the following sound files used in the application:

1. `flip.mp3` - Card flip sound effect
2. `swipe.mp3` - Card swipe navigation sound
3. `favorite.mp3` - Adding to favorites sound
4. `achievement.mp3` - Achievement unlocked sound
5. `error.mp3` - Error notification sound

## Audio Credits

These are placeholder files. For production use, please replace with properly licensed audio files from sources like:

- [Freesound](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

## Usage Notes

- All sound files should be short (less than 1 second)
- Files should be optimized for web (compressed MP3 format)
- Sound effects can be toggled on/off in the app settings
