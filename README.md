# מרחב הדעת - Merhav Hadaat

מרחב הדעת (Space of Knowledge) is a spiritual wisdom card application designed to provide daily insights and wisdom in Hebrew. The application features a beautiful, accessible interface with RTL support and modern animations.

## Features

### Core Features
- **Card-Based Interface**: Flip through wisdom cards with smooth animations
- **Progress Tracking**: Visual progress bar showing completion status
- **Favorites System**: Mark and collect favorite cards
- **Personal Notes**: Add personal reflections to each card
- **Card Sharing**: Share cards as images on social media
- **Categories**: Browse cards by different spiritual topics

### User Experience
- **Onboarding Tutorial**: First-time user guidance
- **Comprehensive Help**: Detailed instructions for all features
- **Keyboard Navigation**: Full keyboard support for accessibility
- **Touch Gestures**: Swipe navigation for mobile users
- **Achievement System**: Celebrate progress milestones

### Customization
- **Theme Options**: Default, Dark, Blue, and Green themes
- **Font Size Settings**: Small, Medium, and Large text options
- **Sound Effects**: Toggle-able audio feedback
- **Data Management**: Import/Export/Reset user data

## Getting Started

1. Open `index.html` in a modern web browser
2. Follow the onboarding tutorial on first launch
3. Navigate through cards using the arrow buttons or swipe gestures
4. Flip cards by clicking/tapping on them
5. Use the control buttons to favorite, add notes, or share cards

## Accessibility Features

- Full keyboard navigation support
- ARIA attributes for screen readers
- Focus management for modals and interactive elements
- High contrast themes
- Adjustable font sizes
- RTL language support

## Technical Details

### File Structure
- `index.html` - Main HTML structure
- `styles.css` - Core styling
- `styles-modals.css` - Modal and component styling
- `script.js` - Main application logic
- `data.js` - Card data and data management
- `ui.js` - UI components and interactions
- `events.js` - Event listeners and handlers
- `sounds/` - Audio files for sound effects

### Technologies Used
- HTML5
- CSS3 (with variables, animations, and responsive design)
- Vanilla JavaScript (ES6+)
- Google Fonts (Assistant and Frank Ruhl Libre)
- html2canvas (for card sharing)
- canvas-confetti (for achievement celebrations)

## Browser Support

This application works best in modern browsers that support:
- CSS Grid and Flexbox
- CSS Variables
- ES6+ JavaScript
- Web Storage API (localStorage)
- Web Share API (for sharing, with fallback)
